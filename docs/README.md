# ballware LLM Service — documentation

This folder documents the LLM Service from the backend side: its HTTP API surface, request/response
payloads, data model, RAG/context pipeline, background jobs, and upstream dependencies. Everything is
derived from the committed OpenAPI snapshot [openapi/llm.json](openapi/llm.json) plus the source code.

> Scope note: this is the **backend view**. The frontend consumption contract (how the platform UI
> interprets tenant entity metadata) lives in the frontend documentation repos and is not duplicated
> here. `ballware-docs` aggregation of these pages is a separate follow-up.

## Quick facts

- One published OpenAPI document: `llm` ("ballware LLM user API", **71 paths**, **17 schemas**,
  OpenAPI `3.0.4`). The second declared document `service` ("ballware LLM service API",
  `src/Ballware.Llm.Service/Startup.cs:178-182`) currently maps **no** operations — see
  [api/README.md](api/README.md).
- Committed snapshot: [openapi/llm.json](openapi/llm.json), provenance in
  [openapi/manifest.json](openapi/manifest.json), regenerated by
  [openapi/fetch-spec.sh](openapi/fetch-spec.sh).
- Swagger UI: `/swagger`; raw documents at `/swagger/llm/swagger.json` and
  `/swagger/service/swagger.json` (`Startup.cs:261-275`).
- Development port: HTTP `http://localhost:5006` (`src/Ballware.Llm.Service/appsettings.Development.json:15-21`).
  The Service image declares `EXPOSE 5000` / `EXPOSE 5001` (`src/Ballware.Llm.Service/Dockerfile:3-4`);
  the App host listens on `http://+:3004` (`src/Ballware.Llm.App/appsettings.json:5`).
- Authentication: JWT bearer against an OIDC issuer; authorization by **scope → policy** — `mlApi`
  for every documented operation, `serviceApi` defined but unused (`Startup.cs:105-119`).
- JSON bodies are **PascalCase** (`PropertyNamingPolicy = null`, `Startup.cs:121-129`), except the
  OpenAI chat payloads, which keep the lowercase OpenAI field names via `JsonPropertyName`.
- Knowledge storage: PostgreSQL + pgvector, `chunk.data` and `image.data` typed `vector(768)`; no ANN
  index (sequential scan ordered by cosine distance).
- Document payloads and image binaries are **not** in the LLM database — they live in the ballware
  Storage Service ([concepts/payload-offloading.md](concepts/payload-offloading.md)).

## Request flow

```text
client (browser / other service)
  |  Authorization: Bearer <token>          SignalR clients may also send ?access_token=
  |                                         for paths under /ai/hubs               Startup.cs:87-102
  v
ASP.NET Core routing + JWT bearer auth                                         Startup.cs:71-103
  |  scope claim -> policy "mlApi" (used) / "serviceApi" (reserved)            Startup.cs:105-119
  v
endpoint handler
   |  5 LLM operations:  /ai/v1/chat/completions, /ai/context/simulatesystemprompt,
   |                     /ai/origin/addfromattachment, /ai/origin/createembedding,
   |                     /ai/embedding/recreate                                 Startup.cs:245-248
   |  66 generic operations: /ai/{context|origin|embedding|chunk|image|session}/…  Startup.cs:250-255
   |    (chat_session rows are additionally owner-filtered by the `sub` claim)
   |  1 SignalR hub: /ai/hubs/chat (outside OpenAPI)                            Startup.cs:244
  v
tenant + entity rights check (Jint scripts, metadata from Meta Service)        Ballware.Llm.Hosting
  |  candidate "ai.<entity>.<right>" evaluated by the tenant RightsCheckScript,
  |  then the entity CustomScripts.extendedRightsCheck
  v
repository (tenant-scoped, Mapster Public <-> Persistables)                    Ballware.Llm.Data.Ef
  |  payload hooks offload Origin.Content / Image binaries                     Ballware.Llm.Hosting/Extensions
  v
PostgreSQL + pgvector (context / origin / embedding / chunk / image / chat_session / chat_message)  Ballware.Llm.Data.Ef.Postgres
  |  top-k retrieval: ORDER BY data <=> query_vector (cosine distance)         ChunkRepository.cs:15-27
  v
OpenAI-compatible inference + embedding endpoints (num_ctx, tool calls, MCP)   Ballware.Llm.Inference.OpenAi
  |
Quartz jobs for ingestion paths: addfromattachment, createembedding,
  recreate, import  ->  Docling Serve, Storage Service, Meta Service            Ballware.Llm.Jobs
```

For setup, prerequisites and build/run commands see the repository [README.md](../README.md). For
OpenAPI regeneration see [openapi/README.md](openapi/README.md).
